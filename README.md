# Java-Ecology-Project

展示 Java 各大中间件生态的标准使用方式（基于 Spring Boot）。

## 目标

- 每个中间件一个独立、可运行的示例模块
- 统一依赖版本、配置规范、测试方式和文档结构
- 示例尽量贴近生产用法，而不是只写 Demo
- 可复制到实际项目，也可作为面试/学习时的参考实现

## 规划

后续逐个补充中间件生态示例，例如：

- 注册中心 / 配置中心
- RPC / HTTP 客户端
- 消息队列
- 缓存 / 分布式锁
- 数据库 / ORM / 分库分表
- 分布式事务
- 可观测性
- 任务调度
- 网关 / 限流 / 熔断

项目初始化中，示例模块后续逐个补充。
